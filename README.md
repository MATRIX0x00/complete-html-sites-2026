# Full HTML Websites

This repository contains multiple complete, responsive HTML website templates you can open directly in a browser.

## Included sites

- Tech Startup
- Restaurant
- Portfolio
- Real Estate
- Fitness Studio
- Travel Agency

## Open a site

- `sites/tech-startup/index.html`
- `sites/restaurant/index.html`
- `sites/portfolio/index.html`
- `sites/real-estate/index.html`
- `sites/fitness/index.html`
- `sites/travel/index.html`

## Quick start

Open any `index.html` file directly in your browser.

You can also serve the repo locally with:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
